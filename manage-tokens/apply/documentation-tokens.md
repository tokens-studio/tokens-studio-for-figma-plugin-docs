# Documentation Tokens

## Documentation Tokens

When you right-click a token in the plugin, you can choose from "Documentation tokens" that let you insert helpful values of the token into the selected Figma layer. This is especially helpful if you're creating documentation (e.g. if you do something like our [Broken link](broken-reference "mention")feature manually).

Start by selecting a text layer, right click for example a color token, and choose Documentation tokens -> Value. This will insert the token's current value into the text layer. You can then try swapping themes (or activating a token set where the token's value would change), and notice that the text layer's value changes too!
